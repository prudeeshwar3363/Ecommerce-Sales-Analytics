# Dataset Information

This project uses a Superstore sales dataset for e-commerce sales and profitability analysis.

## File
- Expected filename: `superstore.csv`
- Expected location: `data/superstore.csv`

## Expected Columns
The CSV should contain order dates, shipping information, customer details, product categories, sales, quantity, discount, and profit.

## Before Sharing
Verify the dataset's source and license before uploading it publicly to GitHub. If redistribution is not permitted, do not upload the CSV; provide instructions for obtaining it instead.

## Import
Use `python/import_superstore.py` to import the CSV into the local MySQL database after configuring the database connection.
